# Fieldy — צ'קליסט בדיקת תקינות ידנית (שלב 0)

הבדיקה האוטומטית (`npm run smoke`) מכסה את רוב הדברים למטה בדפדפן headless.
הצ'קליסט הזה הוא למעבר ידני מהיר **בטלפון האמיתי**, אחרי כל שדרוג, כי יש דברים
שרק המכשיר האמיתי מראה (גופנים, קול, התראות, שרת Cloudflare).

לפני שמתחילים: **הגדרות ← ⬇️ הורד גיבוי.** תמיד. זה לוקח 3 שניות.

## 1. פתיחה
- [ ] האפליקציה נפתחת למסך הבית בלי מסך לבן.
- [ ] בהגדרות, "גרסה" מציגה את המספר החדש (אם לא — "רענן עכשיו").
- [ ] אין שגיאות בקונסול (בכרום בטלפון: `chrome://inspect` מהמחשב, או פשוט לוודא שהכל נטען).

## 2. ניווט — כל טאב נפתח
- [ ] בית · משימות · אתרים · אנשים · לוח · טאו — כל אחד נפתח ומציג תוכן.
- [ ] בטאו: ארבעת תתי-הטאבים (טאו / מנהיגות / ADHD / שיחה) נפתחים; "הקודם / הבא" מחליף פרק.
- [ ] בלוח: שבוע / חודש / שנה, וחיצי הניווט.
- [ ] בית ← "+ הוסף הודעות מוואטסאפ" פותח את מסך הקלט; החץ חוזר הביתה.
- [ ] בית ← ☯️ (למעלה) פותח הגדרות; החץ חוזר הביתה.

## 3. משימות
- [ ] "+ הוסף" ← למלא טקסט ← "הוסף": המשימה מופיעה ברשימה הנכונה (עכשיו/היום/אחר כך).
- [ ] ✎ עריכה משנה את הטקסט ומעבירה בין רשימות.
- [ ] סימון V מסמן כבוצע (צליל + טבעת); 🗑 מוחק.
- [ ] סגירה ופתיחה מחדש של האפליקציה — המשימה עדיין שם (או עדיין מחוקה).

## 4. אתרים
- [ ] "+ הוסף" עם שם + מיקום ← הכרטיס מופיע, ויש בו קישור 🗺️ Maps.
- [ ] ✎ עריכה שומרת שינוי.
- [ ] לחיצה על סטטוס אחר פותחת את חלון האישור; "✓ אשר" משנה את הסטטוס.
- [ ] 🚧 מסמן/מבטל "תקוע"; אתר תקוע מופיע גם במסך הבית.
- [ ] 🔧 אבחון נפתח.

## 5. אנשים
- [ ] "+ הוסף" עם "ממתין ל..." ← מופיע תחת "ממתין תשובה"; ✓ מנקה את ההמתנה.

## 6. לוח
- [ ] "+ אירוע חדש" ← נשמר, מופיע ביום הנכון; ✕ מוחק.

## 7. אימות נתונים (החלק החדש בשלב 0)
- [ ] **גיבוי תקין**: הגדרות ← "טען מקובץ" עם קובץ גיבוי אמיתי ← שאלת אישור ← "✓ הנתונים נטענו".
- [ ] **קובץ לא נכון**: לנסות לטעון קובץ שאינו גיבוי (למשל תמונה או קובץ טקסט) ← הודעה ברורה שהקובץ נדחה, **ובלי** שאלת "להחליף?", והנתונים לא השתנו.
- [ ] (רשות, למי שנוח לו עם כלי מפתחים) לשבש את `fieldy_v2` ב-localStorage ← בטעינה הבאה מופיע מסך אדום "Fieldy לא הצליח לטעון…" עם כפתור הורדה, "נסה שוב" ו"התחל מחדש". הנתונים לא נמחקים לבד.

## 7ב. שלב 2 — UX ל-ADHD
- [ ] **"🎯 עכשיו" בבית**: רשימה אחת מדורגת. הפריט הראשון גדול. לחיצה על משימה פותחת את הרשימה הנכונה; לחיצה על אתר תקוע פותחת אתרים.
- [ ] **מצב רוח משפיע**: לסמן "מוצף" ← בבית נשאר פריט אחד + "הצג הכל (N)"; במסך משימות נשארת משימה אחת + פס הסבר. "פוקוס" מחזיר הכל.
- [ ] **Undo**: למחוק משימה שבוצעה / אתר (מתוך ✎ ← "מחק אתר") / איש קשר (🗑) / אירוע ← מופיעה בועה כהה "בטל" ל-6 שניות ← לחיצה מחזירה את הפריט למקומו.
- [ ] **קלט קולי** (כרום באנדרואיד): "+ הוסף" משימה ← 🎤 הקלט ← לדבר ← הטקסט נכנס בזמן אמת; 🌐 מחליף שפה (עב/EN/FIL). גם בהוספת אתר ובמסך הוספת הודעות. בפעם הראשונה כרום יבקש הרשאת מיקרופון.

## 7ג. שלב 3 — התראות לטלפון (אחרי פריסת ה-Worker, ראה README-DEPLOY.md)
- [ ] הגדרות ← "🔔 התראות לטלפון": הסטטוס מסביר בדיוק מה המצב (לא פעיל / פעיל / חסר שרת / הרשאה נחסמה).
- [ ] "הפעל התראות" ← אישור בכרום ← הסטטוס הופך ל"✓ פעיל במכשיר הזה".
- [ ] "שלח בדיקה" ← התראה מגיעה תוך שניות, גם כשהאפליקציה סגורה. לחיצה עליה פותחת את Fieldy.
- [ ] אירוע בלוח לעוד 15 דקות עם "10 דק לפני" ← התראה מגיעה בזמן (±5 דקות, לפי הקרון).
- [ ] לשנות שעת רפלקציה ← "✓ נשמר" ← בשעה הזו מגיעה תזכורת רק אם לא כתבת היום.
- [ ] "בטל במכשיר הזה" ← הסטטוס חוזר ל"לא פעיל", ובדיקה כבר לא מגיעה.

## 7ד. שלב 4 — עיצוב ומקצועיות
- [ ] **אייקונים**: אין יותר אימוג'י בממשק (ניווט, כפתורים, כרטיסים, טאו). הכל באותו סגנון קו. אם משהו נראה ריק במקום אייקון — לצלם ולשלוח.
- [ ] **מעברים**: מעבר בין טאבים מרגיש חלק (הבהוב קצר), מודאל עולה מלמטה. אם הגדרת "הפחתת תנועה" בטלפון — בלי אנימציות בכלל.
- [ ] **שלדים**: "ארגן את היום" / "שאל את Fieldy" / "נסח למונדיי" מציגים שורות מנצנצות בזמן ההמתנה, לא "...".
- [ ] **מפה**: אתרים ← "מפה" ← סיכות לאתרים עם קואורדינטות, פס קנה מידה, לחיצה על סיכה מציגה פרטים + "ניווט". עובד גם בלי אינטרנט.
- [ ] **גרפים**: בית ← מתחת לכפתורי מצב הרוח רצועת 30 יום (אחרי 3+ ימי סימון). ליקוידציה ← גרף 6 חודשים + לפי ספק.
- [ ] **צליל ורטט**: סיום משימה / שמירת רפלקציה / סיום מדיטציה משמיעים צליל קצר ורוטטים. הגדרות ← "משוב לפעולות" ← לכבות ← שקט לגמרי, והפעולות עדיין מאשרות את עצמן ויזואלית.
- [ ] **תגי-אייקון צבעוניים**: מצב רוח בבית, רשימת "עכשיו", כרטיסי משימות, אבחון SPIS (אתרים ← אבחון) ומסך "צור תוכן" מציגים עיגול צבעוני סביב האייקון, לא רק קו שטוח.
- [ ] **רקע חי**: ברקע האפליקציה (בעיקר במסכים עם מעט תוכן כמו אנשים/משימות ריקות) יש כתמי צבע רכים ומטושטשים שזזים לאט מאוד — לא רקע קרם שטוח אחיד. עם "הפחתת תנועה" מופעל בטלפון, הכתמים נשארים במקום.

## 7ה. שלב 5 — עוזר אחד (הקשר משותף, תדריך בוקר, קיבוץ משימות)
- [ ] **תדריך הבוקר**: בבית, מתחת לכותרת, כרטיס "☀ תדריך הבוקר" — מוקד היום, עד 4 אתרים לתשומת לב (תקועים קודם), מוקד המנהיגות השבועי. עם שרת מחובר: גם 3-4 משפטים שנכתבו על ידי AI. בלי לרענן — נכתב פעם אחת ביום; "רענן" כותב מחדש עם עוד קריאה אחת.
- [ ] **בלי שרת**: אותו כרטיס מופיע עם העובדות בלבד (בלי הטקסט של AI), ורמז "חבר שרת בהגדרות" — בלי שום קריאת AI.
- [ ] **הקשר משותף**: "שאל את Fieldy", ניסוח הודעה/מייל/מונדיי, וניתוח דפוסים אישיים — כולם "יודעים" את מצב הרוח שסימנת היום, המוקד, והאתרים התקועים בלי שתצטרך לחזור ולהקליד את זה.
- [ ] **הצעת קיבוץ משימות**: אם יש 2+ משימות פתוחות לאותו אתר (או לאותו תאריך עתידי) שמפוזרות בין "עכשיו/היום/אחר כך" — מופיעה הצעה כחולה מתחת לפילטרים. "קבץ" מזיז אותן זו לצד זו (עם אפשרות ביטול); "לא עכשיו" מסתירה עד שהקבוצה משתנה.

## 7ו. סקירת משימות יומית + מוקד ניתן-לעריכה (בתוך תדריך הבוקר)
- [ ] בית ← "תדריך הבוקר" ← "סקור משימות" ← נפתח checklist של כל המשימות הפתוחות מ"עכשיו"/"היום", כולן מסומנות כברירת מחדל.
- [ ] ביטול סימון על משימה ← קו חוצה על הטקסט. "משהו חדש להוסיף?" ← הקלדה + ➕ מוסיפה משימה חדשה ל"היום" מיד.
- [ ] "סיימתי לסקור" ← משימות לא-מסומנות עוברות ל"אחר כך" (עם בועת "בטל"), ומופיעה "נקודת התחלה מוצעת" עם המשימה הכי דחופה שנשארה.
- [ ] "הדבר הכי חשוב היום" בתדריך ← לחיצה פותחת עריכה מקומית עם שדה טקסט + ✓ לשמירה — משנה את "המוקד" בלי לצאת מהבית.
- [ ] אחרי סקירה, הכפתור עובר ל"נסקר היום" (עדיין אפשר ללחוץ ולערוך שוב במהלך היום).

## 7ז. שפת ממשק (עברית/אנגלית)
- [ ] הגדרות ← "שפת ממשק" ← "English" ← כל הממשק (ניווט, כותרות, כפתורים, בית, הגדרות, משימות/אתרים/אנשים) הופך לאנגלית, הכיוון הופך ל-LTR (הניווט התחתון עובר לסדר בית-משימות-אתרים...).
- [ ] תוכן שנכתב על ידך (טקסט משימה, שם אתר, הערות) **נשאר בעברית** בלי תרגום אוטומטי — זה נתון שלך, לא ממשק.
- [ ] הציטוט היומי, תוכן הטאו (פרקים/מדיטציות/מוקד השבוע), והתדריך שנוצר על ידי AI **תמיד בעברית**, גם באנגלית.
- [ ] סוגרים ופותחים את האפליקציה מחדש ← השפה שנבחרה נשארת. "עברית" מחזיר הכל.
- [ ] **ידוע וטרם מתורגם בסבב הזה**: תוכן פנימי של מודלים (הוספת/עריכת אתר-משימה-איש קשר), מסכי לוח שנה/פעולה/קלט, ואבחון ה-SPIS — עדיין בעברית גם במצב אנגלית. ניתן להרחיב בהמשך לפי אותה תבנית (`tr('key')`).

## 8. שרת (אם מחובר ל-Cloudflare)
- [ ] הגדרות ← "בדוק חיבור" ← "✓ מחובר!".
- [ ] שינוי במשימה במכשיר אחד מופיע במכשיר השני אחרי רענון.

## 9. דברים שהבדיקה האוטומטית לא יכולה לבדוק
- [ ] "⚡ ארגן את היום" עם הודעה אמיתית מוואטסאפ (דורש חיבור לשרת).
- [ ] "שאל את Fieldy" עונה.
- [ ] מדיטציה: צליל, מוסיקה, קול הדרכה, סיום מוקדם.
- [ ] התראה על אירוע (אם ההרשאה ניתנה).
